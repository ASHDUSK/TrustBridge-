TrustBridge 项目入口说明（本文件描述各启动器用途，双击对应 .bat 即可）
==========================================================================

【每天用】启动应用.bat
    启动 MedBridge Studio 翻译应用 → 20 秒后自动打开浏览器
    http://127.0.0.1:7860
    （黑窗口保持开着 = 应用在运行；关掉黑窗口 = 应用停止）

【学习/答辩准备】论文精读教程
    打开 docs_论文精读教程.html —— 逐章逐式拆解论文、数字溯源、
    答辩十问、15 道自测题（公式渲染需联网一次）。

【写论文/汇报时】打开论文.bat
    同时打开两个文件（无需启动任何服务）：
    1. paper_preview.html —— 论文预览（公式渲染需联网一次）
    2. TrustBridge_paper_draft.pdf —— 8 页静态稿（完全离线）
    两个文件本身在 docs\latex\ 目录，也可以不经过 bat 直接双击。

【可选】启动看板.bat
    打开实验进度看板 http://127.0.0.1:8018（训练/下载实时状态）。

----------------------------------------------------------------------------

手动命令版（如果 .bat 丢失，等价命令如下）：

  启动应用:
    cd /d D:\MedTranslateProject
    set NO_PROXY=localhost,127.0.0.1
    python app\app.py
    （浏览器打开 http://127.0.0.1:7860）

  打开论文 PDF:
    start "" "D:\MedTranslateProject\docs\latex\TrustBridge_paper_draft.pdf"

  LaTeX 编译（投稿版，需上传 Overleaf 或本地装 MiKTeX）:
    main.tex + references.bib + related_work.tex 三个文件即可编译

----------------------------------------------------------------------------

注意：
- 训练期间（GPU 占满）应用会显存不足，等训练结束再用；
- 代理/VPN 开着不影响以上入口（已内置绕行规则）；
- 关机后所有服务自动停止，双击对应 .bat 即可恢复。
