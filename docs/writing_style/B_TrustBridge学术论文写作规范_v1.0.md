# B · TrustBridge 学术论文写作规范 v1.0

> 依据：A 报告中 10 篇参考论文的**交集**规范 + 医学影像 AI 领域惯例。
> 效力范围：TrustBridge 论文中英文稿；对既有内容做"检查-改写"，对新内容做"生成约束"。

## 1. 各章节写作目的与推荐结构

| 章节 | 目的 | 推荐结构 |
|---|---|---|
| 摘要 | 让读者 60 秒判断是否相关 | 背景→现有方法的具体失效→"本文提出"→机制 2–4 句→评价范围+克制比较级结论。**不放主指标数值**（≤3 个辅助数字） |
| 引言 | 建立动机→缺口→科学问题 | 临床动机（引文）→任务难度形式化→方法族演进各带局限→gap 句→"本文"段→贡献条目（≤4） |
| 相关工作 | 脉络+定位 | 按方法族组织；每族以局限收尾；每篇被引文献承担明确证据角色；末尾定位句"Unlike X, we ..." |
| 方法 | 可复现的形式化 | 符号一次定义沿用；公式编号；假设与算子（归一化/阈值）显式声明；实现差异单独小节 |
| 实验 | 数据支持的回答 | 每实验：目的→设置→结果→一句解读；解读性收束每段最多一句 |
| 讨论 | 机制解释与边界 | 发现→机制→适用条件→与其他工作关系；**不新增结果数字** |
| 局限 | 客观自限 | 每条局限=缺陷+后果+缓解方向；不用免责套话 |

## 2. 学术段落组织

- **段首主题句**陈述该段唯一主张；段内按"证据→推理"展开；段尾不重复主题句。
- 一个主张一个位置：同一解读不在结果与讨论重复出现（结果留数据+一句收束，机制解释归讨论）。
- 转折用逻辑连接词（however/yet/therefore），不用修辞排比堆叠。

## 3. 结果与讨论的边界（硬规则）

- 结果章节禁止出现：部署建议、领域启示、对其他方法的教训句。
- 结果章节允许：直接数据支撑的一句解读 + 交叉引用（"(\S\ref{sec:discussion})"）。
- 讨论章节禁止出现：未在结果出现的新数字。

## 4. 科学结论的措辞强度阶梯

```
证明级（仅定理）：prove / establishes
数据级：demonstrate（直接数据）/ indicate / suggest
倾向级：is consistent with / may / can
禁止：证明用于实证；"全面""唯一""彻底解决"；无"can/may"的普适否定与肯定
```
比较结论必须绑定比较对象与协议："outperforms equal-budget dispersion baselines
under the within-body protocol"（不说"优于现有方法"）。

## 5. 术语/公式/变量规范

- 术语首次出现给英文全称+缩写，此后只用缩写；
- 一个概念一个符号（CReF 不与 RCRF 混用；trust/T 单义）；
- 每个公式中变量在随文定义；算子类参数（p99、0.02、K₀、0.6/0.4）在 Tab impl 冻结并给敏感性指针；
- 统计表述三件套：点估计±SD（注明切片级）+CI（注明单位）+n。

## 6. 应避免的项目报告式/宣传式表达（黑名单）

| 类型 | 例子 | 处理 |
|---|---|---|
| 内部文档引用 | docs/18、reports/、内部表格 | 改为论文级指称（released analysis scripts / a documented audit trail） |
| 产品化命名 | "系统：TrustBridge"入标题副题；UI 引用入正文 | 标题副题去"系统"；UI 一律不入正文 |
| 工程动词 | harvest/收割、拆成两层、上线 | extract/derive；系统划分用 method-level 语言 |
| 口号式对句 | "a signal, not a gate"、"知道自己不知道" | 至多保留一处且改为限定句式 |
| 夸大比较 | "全面优于""远超" | 绑定对象与协议的比较级 |
| 免责套话 | "仅供研究使用"类空话 | 换为具体后果陈述（例：PASS/REVIEW 阈值未经临床标定→不得用于自动放行） |

## 7. 医学影像 AI 论文特殊要求

- 临床断言分层：合成质量 → 排序有效性 → 临床效用；只主张已验证层，下层用"intended to / candidate evidence for human review"；
- 患者级 vs 切片级统计必须随数字声明；
- 阴性结果与失效边界是贡献的一部分（对照 Hallucination Index 的 "warning label" 定位、RAISE 的 guardrail 生命周期语言）；
- 与监管/报告框架（AI-RADS、RAISE）的关系用"complementary/provides evidence called for"定位，不自称满足任何框架。

## 8. 修订优先级规则

1 先改"主张与证据不匹配"，2 再改"结构错位"（讨论内容在结果），3 最后改"措辞风格"；
所有修改保持数字、协议、结论立场不变（见任务约束 1–10 条）。
