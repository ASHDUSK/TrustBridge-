# TrustBridge 改进路线图（详细执行方案）

> 目标：把项目从"扎实的复现 + 推理层创新"推进到"方法级创新 + 广泛验证"，面向国赛/论文。
> 建议周期：5-6 周（可并行压缩到 4 周）。每阶段给出：动机 → 技术设计 → 执行步骤 → 验收标准 → 工作量。

---

## 阶段一（P1，最高优先）：信任图引导的自适应采样 —— 让地图"指挥行动"

### 动机
当前信任图只做"事后诊断"。把它变成采样过程的**控制器**，故事从"仪表盘"升级为
"可信度驱动的自适应翻译框架"——这是方法级创新的门槛。

### 技术设计（三个机制，由易到难）

**机制 A：块级自适应递归（必做）**
- 把 256×256（或 128×128）图像切成 K×K 个图块（建议 4×4）；
- 每个反向步的递归循环中：计算每块的递归残差，**已收敛的块冻结其估计**（不再前向），
  未收敛的块继续递归，直到全部收敛或达到 R_max；
- 实现：递归循环内对生成器输出按块掩码合并（`out = torch.where(converged, old, new)`）；
- 收益：简单图像提前结束（省时），难块获得更多修正。

**机制 B：集成预算再分配（必做）**
- 先用 N₀=2 次采样算出初步信任图；对低信任块追加 M 次采样（高信任块不再采样）；
- 最终输出：高信任块用 N₀ 均值，低信任块用 N₀+M 均值（该区域方差估计也更准）；
- 关键约束：**总前向次数与均匀 N 次基线对齐**（公平比较）。

**机制 C：信任引导早停（选做）**
- 若初步信任图整体很高（简单输入），直接跳过后续递归/加大步长跳跃——难例多花时间，易例秒出。

### 执行步骤
1. `TrustSampler` 重构为块级预算调度器（保留原均匀模式作为基线开关）；
2. 在测试集 60 切片上跑"质量-耗时"扫描：固定总预算，比较均匀 vs 自适应；
3. 出三条曲线：整体 PSNR vs 耗时；低信任区误差 vs 耗时；Trust Score 校准变化。

### 验收标准（满足其一即成功）
- 同等耗时下整体 PSNR 提升 ≥0.3 dB，且低信任区域误差下降 ≥5%；
- 或 PSNR 持平而耗时下降 ≥30%。
- 附带产出：一张"预算-质量"曲线图（答辩利器）。

### 工作量
代码 2-3 天 + 实验 2-3 天。

## 阶段二（P1）：不确定性方法基线对照 —— 证明"又准又省"

### 基线集（按公平性排列，算力对齐）
| 基线 | 做法 | 单图成本 |
|---|---|---|
| 测试时增强 TTA | 输入做小角度旋转/翻转/微噪声，N 次前向取分歧 | 与我们相同（N 次全采样） |
| 输入噪声 TTA | 输入加微小高斯噪声 N 次 | 同上 |
| 纯集成（消融） | 只用我们的②，不用①（w₁=0） | 同上 |
| MC Dropout | 生成器 dropout 置 0.1，用我们权重微调 3 epoch 激活后推理 N 次 | 同上 |
| **TrustBridge（ ours）** | RCRF + 集成融合 | 相同 |

### 执行步骤
1. 统一评测框架：同 60 测试切片、同 N=4 算力、同指标（AUROC / 稀疏化 / Spearman）；
2. 逐基线实现（每个半天）；
3. 出对照表 + 成本对照（每方法额外耗时秒数）。

### 验收标准
TrustBridge 在 AUROC 或稀疏化上不输任何基线，且在"单位时间信息量"上占优；
若某基线更强，如实报告并分析原因（这同样是有效结论）。

### 工作量
3-4 天。

## 阶段三（P2）：第二数据集 + 病理案例（演示与广度）

### 3A：BRATS（脑肿瘤， Killer Demo）
- 官方仓库自带 BRATS 数据制备脚本与预训练权重（t2→t1 / t1→t2 / flair↔t2）；
- 数据源：BraTS2021 公开镜像（HuggingFace/ Kaggle），取 10-20 例即可演示；
- 交付：应用新增 BRATS 任务；产出**肿瘤区信任图案例**（模型在瘤缘不确定度飙升 →
  提示医生重点复核——这是全项目最有说服力的一张图）；
- 风险：数据下载（用 hf-mirror 分段下载器已就绪）。

### 3B：MRI→CT（放疗叙事，可选）
- 官方 ct_t1_ct / ct_t2_ct 权重已有下载地址；
- 数据（Gold Atlas 盆腔）若不可得，则应用先支持"用户自带数据"模式，演示用公开样例。

### 验收标准
应用新增 ≥2 个数据集任务；产出 ≥3 张病理案例信任图；第二数据集上有可汇报的定量表。

### 工作量
2-4 天（数据获取为最大变数）。

## 阶段四（P2）：图像级 QC 增强

### 动机
图像级 Trust Score 与 PSNR 的秩相关目前 0.37/0.49，偏弱。

### 做法（递进）
1. **仅脑区内统计**：背景像素稀释了分数（官方评估也用 mask）；
2. **多特征 QC**：特征 = [脑区内信任均值、低信任面积占比、RCRF 高分位、收敛步数、
   频域残差能量]，拟合一个逻辑回归/梯度提升小模型输出图像级分数；
3. 用验证集拟合、测试集汇报秩相关。

### 验收标准
图像级秩相关 ≥0.6；QC 三级分档与人工标注（可自行标注 30 张）一致率 ≥80%。

### 工作量
2-3 天。

---

## 阶段五（P3）：质量与实用性

### 5A：直方图匹配后处理（高性价比，强烈建议先做）
- 动机：原始口径 PSNR（19.8/20.4）与校正口径（31.7/32.5）之间的差距主要是全局强度映射；
- 做法：合成结果对"参考 T1 强度模板"（训练集均值图像或其直方图）做直方图匹配，
  或学习一个单调 tone-mapping；
- 预期：原始口径 PSNR 19.8 → 24+（几乎零成本）；让应用输出在放射科医生眼里更"正常"；
- 工作量：1 天实验 + 0.5 天集成。

### 5B：更大规模训练（视算力）
- 方案一：本机 256²（batch 2、~10 小时/方向，过夜）；
- 方案二：租云卡（4090）按官方原始 50 epochs 复刻——产出"完全对齐论文设定"的数字；
- 方案三：128² 继续 +100 epochs + 权重 EMA（最省）。

### 5C：实用性证据链
- 软著申请（说明书可直接由 docs/04 手册 + 源码整理）；
- 邀请 2-3 位医学影像方向师生试用，出结构化反馈表（各 30 分钟）；
- DICOM 输出（Secondary Capture）与匿名化说明。

## 风险与对策

| 风险 | 对策 |
|---|---|
| BRATS 数据下载受限 | 用 hf-mirror 分段下载器；或改用 CT 任务/公开样例 |
| 自适应采样收益不显著 | 如实报告并分析（块划分粒度/冻结策略可调参再试）；结论本身有价值 |
| MC Dropout 微调破坏生成质量 | 只微调 3 epoch 并监控 val PSNR，跌了就放弃该基线 |
| 云算力预算 | 全部实验都有本机降级方案 |

## 一句话版本（给老师/评委）
