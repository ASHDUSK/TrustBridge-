# MedBridge Studio 应用使用手册

> 版本：v0.1.0 ｜ 适用平台：Windows 10/11 64 位（Linux 同理）｜ 界面语言：中文

---

## 一、启动与打开

```bash
# 方式一：源码运行（需已装环境并下载权重）
python app/app.py

# 方式二：离线零安装包
# 解压 MedBridgeStudio_Demo.zip → 双击「启动.bat」
```

启动后浏览器自动打开 `http://127.0.0.1:7860`（没自动打开就手动输入）。
关闭黑色的控制台窗口即退出应用。

> **当前看到的是设置面板？** 右上角的 Settings 是 Gradio 自带的外观设置（主题/字体），点 × 关闭即可回到主功能界面。

## 二、界面总览

主界面分五个标签页：

| 标签 | 用途 |
|---|---|
| 🖼 单图翻译 | 核心功能：单张切片的模态翻译 + 可信度评估 + 质控报告 |
| 📦 批量质控 | 对整个文件夹/多文件逐张翻译，输出汇总 CSV 与低信任占比排序图 |
| 🧠 整卷翻译 (NIfTI) | 整个三维 MRI 体数据逐层翻译并导出 |
| 🕓 历史记录 | 回看本机跑过的质控报告（可一键清空） |
| 📖 关于 / 创新点 | 方法说明、引用与免责声明 |

## 三、单图翻译（逐步操作）

### 第 1 步：上传影像
支持三类文件：
- **PNG / JPG / BMP / TIFF** 灰度切片图（最常用，示例可直接点选）；
- **.nii / .nii.gz**（NIfTI 三维卷，默认自动取中间层，可在"切片号"框指定任意层）；
- **.dcm**（DICOM 单帧）。

上传后文件会出现在输入框中；点 × 可清除重选。

### 第 2 步：（可选）上传参考真值
如果你手上有同一层的**目标模态真值图**，一并上传——应用会自动计算 PSNR / SSIM
（与 SelfRDB 论文同口径）并在结果中显示。没有真值也完全可以使用，指标区会显示"演示模式"。

### 第 3 步：选择翻译任务
任务列表只显示**权重已就位**的方向：

| 任务 | 说明 | 推荐用途 |
|---|---|---|
| T2→T1 / T1→T2 | 官方 IXI 预训练权重，256×256，质量最佳 | 正式演示、出报告 |
| PD→T1 / T1→PD | 官方权重（需另行下载 PD 权重） | 扩展任务 |
| T2→T1\* / T1→T2\* | 本项目自训练模型，128×128，速度最快 | 日常浏览、快速筛查 |

> 源图与任务方向要匹配：给 T2 图就选"T2→xx"方向的任务，否则输出无意义。

### 第 4 步：选择质量档位

| 档位 | 行为 | 耗时（RTX 4060） | 适用 |
|---|---|---|---|
| 快速 ⚡ | 单次采样 + 步长跳跃 | ~2-3 秒 | 浏览筛查、整卷处理 |
| 平衡 ⚖（默认） | 4 次集成采样，逐步 | ~5-8 秒 | 日常推荐 |
| 精细 🔬 | 8 次集成采样，逐步 | ~10-15 秒 | 出正式报告，信任图最可靠 |

### 第 5 步：微调参数（一般不用动）
- **低信任标红阈值**（默认 0.6）：叠加图上"低于该信任度的像素"标红，调低→红区更小更严格；
- **随机种子**：固定种子可复现同一结果；换种子可观察输出的稳定性；
- **NIfTI 切片号**：仅上传 NIfTI 时有效，默认取中间层。

### 第 6 步：点「🚀 开始翻译」并等待
- 首次使用某任务会先加载模型（20-40 秒），之后每次都很快；
- 进度条显示当前反向步/集成批次。

### 第 7 步：解读结果

**四张结果图（左上→右下）：**

| 图 | 怎么读 |
|---|---|
| 源图像 | 你上传的输入 |
| 翻译结果 | AI 生成的目标模态 |
| 信任图（亮=可信） | 每个像素的"可信度"：**亮区**=模型多次采样自洽收敛；**暗区**=模型反复修改仍不稳定，即幻觉候选区 |
| 低信任叠加 | 在翻译图上把信任度低于阈值的区域标红——**红色区域应当重点人工复核** |

**主视觉：低信任区域占比（%）。** 即信任度低于阈值的像素占全图的比例——这是**推荐的主要判读量**。
顶部大字就是它，配色同时给出质控建议（PASS / REVIEW / REJECT）。

**Trust Score（0-100）：** 融合信任图的图像级均值，已降为**参考值**。
- **≥ 75：PASS（通过）**——整体可信；
- **55-75：REVIEW（建议人工复核）**——存在明显不确定区域；
- **< 55：REJECT（不建议使用）**——大面积不可信，建议更换输入或放弃该合成结果。

> ⚠️ **为什么总分只是参考**：我们的实测显示，图像级简单聚合与真实误差的相关性有限
> （IXI 上 +0.37、CT 上 −0.63，已写入论文的 limitation）。**请以像素级信任图和低信任区域占比为准。**
> 另外，图像级总分**检测不到"喂错序列"**——实测把 T1 图喂给 T2→T1 任务，Trust Score 仍有 92.9 分，
> 只有输入模态门控能把它揪出来。阈值 PASS≥75 / REVIEW≥55 是演示默认值，**未经临床标定**。

**信任度分布直方图：** 把全图像素按信任度分 10 箱，看"低信任尾巴"有多重；长尾明显时即使总分高也要谨慎。

**低信任连通区域 Top-5 表：** 把像素级证据升级为"哪几块要看"——列出每个低信任连通块的面积(px)、
占比(%)、质心(行,列)、区域平均与最低信任值，可直接定位到具体位置。

**质量指标：** 上传了参考真值时显示 PSNR(dB) 与 SSIM(%)（≥30dB / ≥90% 为优秀水平）。

**质控报告：** `qc_report.png`（六宫格：源图/翻译/信任图/叠加/误差或不确定性/收敛曲线）
与 `qc_report.json`（全部参数、分数、逐层递归收敛记录），可直接归档。

### 信任图的典型"亮灯"位置（经验）
- 组织边界（脑脊液/灰质交界）、颅骨与头皮脂肪区；
- 输入图里的伪影、遮挡区域附近；
- **病灶区域**（本项目用健康脑训练，遇到病变输出会更不确定——这恰恰是提示"此处需要医生重点看"的信号）。

## 四、批量质控（文件夹 / 多文件）

适合"手上有一批切片，先快速筛出哪些需要人工复核"的场景。

**输入（二选一）：**
1. **文件夹路径**：直接填本机路径，例如 `D:\MedTranslateProject\app\examples`（会递归扫描子目录）；
2. **多文件上传**：在上传框里一次选中多个文件（可不填路径）。

**参数：** 数据集/任务（与单图页一致）、质量档位（批量建议「快速」）、低信任阈值、
**最多处理张数**（默认 20，填 0 表示不限）、**是否逐例保存报告**（勾上会为每张图单独存 PNG/JSON，更慢）。

**输出：**
| 产物 | 说明 |
|---|---|
| 汇总 CSV | 逐例一行，列名与实验脚本 `scripts/eval_gt_trust.py` 的口径一致，可直接进统计/论文表格 |
| 低信任占比排序图 | 横条图，按"低信任区域占比"从高到低排序，红=REJECT 橙=REVIEW 绿=PASS |
| 最需复核 3 例 | 占比最高的三张的信任图，直接看哪里不可信 |
| 逐例报告（可选） | 会话目录 `per_case/` 下每张图一份 `qc_report.png` / `.json` |

**CSV 列：**

| 列 | 含义 |
|---|---|
| `file` / `task` / `preset` | 文件名、任务、质量档位 |
| `input_gate` | 输入模态门控结果：`PASS` / `FLAGGED`（喂错序列）/ `skipped`（CT 任务不适用） |
| `trust_score` | 图像级信任分（参考值） |
| `lowtrust_ratio_pct` | **低信任区域占比（主指标）** |
| `qc_flag` | PASS / REVIEW / REJECT |
| `n_lowtrust_regions` / `max_region_pct` | 低信任连通块数量 / 最大块占比 |
| `psnr_db` | 仅当有参考真值时（批量模式通常为空） |
| `elapsed_s` | 该例耗时 |
| `w_rcrf` / `w_unc` | 本次使用的融合权重（按任务族取自消融最优） |
| `lowtrust_thresh` | 本次使用的低信任阈值 |

> 💡 **批量门控的价值**：实测把 T1 图混进 T2→T1 的批量任务里，`input_gate` 会标 `FLAGGED`，
> 而这张图的 `trust_score` 仍有 92.9 分、`qc_flag` 仍是 PASS——**只看总分会漏判，门控不会**。

## 五、整卷翻译（NIfTI）

1. 切到「🧠 整卷翻译」标签，上传整个 `.nii / .nii.gz`；
2. 选任务与档位（**建议快速 ⚡**，整卷约几分钟）；
3. 点「🚀 翻译整卷」，进度条逐层推进；
4. 得到：
   - **翻译后 NIfTI**（与原卷同几何，直接下载）；
   - **中央切片预览图**（源 vs 合成对比）；
   - **逐层 Trust Score 曲线**（低于 55 的层建议人工复核）；
   - 汇总统计（处理层数 / 耗时 / 平均与最低分）。

> 空层或脑组织过少的层不会生成，直接沿用源切片。

## 六、常见问题（FAQ）

| 现象 | 原因与解决 |
|---|---|
| 浏览器打不开 7860 | 应用进程未启动（重新运行 `python app/app.py`）；或开了代理/VPN——启动脚本已内置绕行，若手动启动请在命令前加 `set NO_PROXY=localhost,127.0.0.1`（Windows） |
| 端口被占用 | 7860 被其他程序使用时，关闭占用程序，或修改 `app/app.py` 末尾的 `server_port` |
| 第一次点翻译很慢 | 正在加载模型（20-40 秒），属正常；之后每次都快 |
| 报显存不足 (OOM) | 关闭其他占显存的程序；或切到"快速"档；或确认没有同时跑训练 |
| 没有显示 PSNR/SSIM | 未上传参考真值，或真值与输入尺寸不一致（已自动跳过对比） |
| 翻译结果整体偏亮/偏暗 | 自训练模型（\* 后缀）的正常现象，全局强度映射与训练数据窗有关；结构（解剖形态）是可靠的 |
| CPU 电脑能跑吗 | 能，但每张图需 1-5 分钟，建议只用"快速"档 |
| 训练期间能用应用吗 | 不能：训练占满 8GB 显存，推理会 OOM；训练结束后恢复 |

## 七、质控报告（JSON）字段说明

| 字段 | 含义 |
|---|---|
| trust_score | 图像级信任分（0-100，融合图均值）——**参考值**，见 limitation 说明 |
| trust_score_meaning | 该字段自带说明：图像级聚合与真实误差相关性有限，请以像素级信任图与 lowtrust_ratio_pct 为准 |
| qc_flag | PASS / REVIEW / REJECT 质控结论 |
| lowtrust_ratio_pct | **低信任区域占比（主指标）**，即信任度 < lowtrust_thresh 的像素百分比 |
| lowtrust_thresh | 本次使用的低信任阈值（默认 0.60，可调） |
| trust_hist_pct | 信任度 10 箱直方图（每箱占全图百分比） |
| fusion_weights | 本次使用的 RCRF / 不确定性融合权重 |
| qc_note | 质控结论的文字解释 |
| input_gate / input_gate_prob_t2 | 输入模态门控结果（PASS / FLAGGED）与判为 T2 的概率 |
| n_ensemble / step_skip | 本次使用的集成采样数与步长跳跃 |
| recursions_per_step_first_member | 每个反向步实际使用的递归次数（自适应停机记录） |
| step_residual_curve_first_member | 每个反向步的末次递归残差（收敛曲线数据） |
| quality_metrics_official_protocol | PSNR/SSIM（仅当提供参考真值） |
| disclaimer | 免责声明 |

## 八、使用边界（务必阅读）

1. 本应用产出**仅供科研、教学与演示**，**不得**直接用于临床诊断、治疗决策或放疗剂量计算；
2. 信任图/Trust Score 是"模型不确定性的工程证据"，**不构成医学判断**；即使 PASS 也应人工阅片；
3. 低信任区域 ≠ 一定错误，它提示"模型在此处证据不足"，需要专业人员复核；
4. 处理与报告均在本地完成，不上传任何数据。
