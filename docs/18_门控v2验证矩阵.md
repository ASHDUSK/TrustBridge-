# 18 · 输入门控 v2：6 类模态/解剖分类 + OOD 拒判 —— 验证矩阵（2026-11-01）

## 1. 动机

应用的最坏失败模式不是"翻译得差"，而是**对不该翻译的输入伪造一份带信任评分的报告**：
喂错模态（T1 喂给 T2 源任务）、喂错解剖部位（盆腔 CT 喂给脑任务）、
甚至喂入非医学图像（噪声/截图），系统都会照常合成并打分。
门控 v1（`trustbridge/gate.py`，T1/T2 二分类）只能覆盖第一种情况。
门控 v2 把"输入是否属于本任务的分布"变成三档判定：

| 判定 | 含义 | 应用行为 |
|---|---|---|
| **MATCH** | 输入与任务声明的源模态/解剖一致 | 放行 |
| **MISMATCH** | 是医学图像，但不是任务要的模态/部位 | 脑任务**硬拒绝**；CT 任务警示放行（见 §5） |
| **OOD** | 域外输入（平坦图 / 距所有类中心过远） | **硬拒绝：不合成、不出评分** |

## 2. 模型

- **类别（6）**：brain_T1 / brain_T2 / brain_FLAIR / pelvis_T1w / pelvis_T2w / pelvis_CT
- **特征**：统一 128² 重采样 → 体区标准化分位数（8）+ 梯度统计（2）+ 高亮占比（1），
  共 11 维，线性强度不变量（复用 `gate_features`）
- **分类器**：标准化空间多项 Logistic Regression，系数导出 npz，**推理端零 sklearn 依赖**
- **OOD 打分**：到 6 个类中心的最小 Mahalanobis 距离；τ = 验证集 99.5 分位 = **388.76**
- **训练数据**：IXI T1/T2（train+val）、BraTS2018 FLAIR、FeTS FLAIR（隔片）、
  SynthRAD 盆腔 T1w/T2w（患者级划分）、SynthRAD CT
- **精度**：eval 分类 acc **0.9827**；模型 `trustbridge/modality_gate_v2.npz`，
  训练/验证脚本 `scripts/train_gate_v2.py`

## 4. OOD 探针的标签归因（诚实记录）

探针并非全部走 Mahalanobis 路径被标 OOD：

- **平坦/常数图**（28 例）：被"体区标准差近零"硬规则直接判 OOD ✅
- **噪声/棋盘/平滑斑**（45 例）：maha 38.8–139.8，**低于 τ=388.76**，
  但被分类器归入脑类 → 判 MISMATCH。
  原因：τ 被 FeTS（跨扫描仪域移位）验证切片抬到了 388；合法数据 maha 全部 ≤ 40.8，
  探针 ≥ 38.8，两者只在 BraTS FLAIR 尾部有 2 个单位重叠，**不存在能同时
  不误拒合法数据、又把全部探针标为 OOD 的全局阈值**。
- 4 例 SKIP：体区过小，无法提特征（应用中不拦截，由用户自行确认）。

结论：对合成探针的实际拦截由**分类器（MISMATCH）+ 应用策略（脑任务硬拒绝）**完成，
Mahalanobis 只负责最极端的分布外情况。这不影响安全性质，但 OOD *标签*的覆盖
弱于设计预期——记为局限，不是缺陷。

## 5. 应用策略（app/app.py，已集成）

`trustbridge/gate_v2.py` 的 `gate_decision()` 在三处生效（单图 / 整卷 / 批量）：

1. **OOD → 硬拒绝**：`gr.Error`，不进入合成管线，不产生任何评分/报告；
2. **MISMATCH → 脑任务硬拒绝**（验证矩阵 0% 误拦，可放心硬拒）；
3. **MISMATCH → CT 任务警示放行**：盆腔 T1w 未见患者有 52.5% 被误判为脑类，
   硬拒绝会拦掉一半合法输入；改为警示 + 报告标题标注"输入校验未通过"，
   QC JSON 记录 `input_gate=MISMATCH / pred_class / maha`。
4. **批量 QC**：block 级输入不合成，CSV 记 `qc_flag=GATE_BLOCKED`，
   其余判定进 `input_gate` 列。

已知取舍（写进局限）：CT 任务上噪声类探针会以 MISMATCH 警示放行
（特征空间无法把"未见患者盆腔 T1w"与"脑类"分开，放宽拦截必然连带放行噪声）；
对安全性要求更高的部署可把 CT 任务也设为硬拒绝，代价是 52.5% 合法误拦。

## 6. 与其它结论的关系

- 门控 v1（`gate.py`）保留作 T1/T2 二分类兼容层，v2 在其特征函数之上构建；
- 盆腔门控 v1 失败结论（docs/12 表 6）仍然成立——v2 的做法是**组期望**而非
  更强的 T1w/T2w 区分：承认区分不可靠，只验证"是盆腔 MRI"；
- 肿瘤-信任 AUROC 0.871 已被修正为**体区内 0.51±0.10**（chance；
  旧数值被背景空气负例虚高，见仓库提交 217cf61 与 scripts/eval_tumor_corrected.py）——
  引用肿瘤验证结论时一律以修正版为准。
