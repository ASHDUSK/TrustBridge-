# 消融实验报告：创新点组件逐项验证

> 基座模型固定（自训练 T2→T1 / T1→T2，128²，30 epochs），消融对象为信任评估层的各组件。
> 全部数据：`outputs/ablation/`（逐切片 CSV + 聚合 JSON + 运行清单），测试集 60 切片，种子 2026。

## 三、结论解读

1. **每个模块单独加都有效**：最便宜的 RCRF-only（N=1，一半成本）AUROC 就有 0.792/0.880
   （随机下限 0.50）；集成不确定性单独使用 0.806/0.897。两个模块都不是摆设。
2. **融合优于任何单模块**：完整方案在两个方向的 AUROC（0.816/0.900）与稀疏化增益上
   均为最高（T1→T2 的 Spearman 上 unc 单独略高 0.016，但在 AUROC/稀疏化上融合最优）——
   两类信号互补（残差捕捉"收敛稳定性"，集成捕捉"采样一致性"）。
3. **模块贡献排序**：集成不确定性（②）单项略强于递归残差（①）约 0.01 AUROC；
   但①可在**一半成本**下达到 ②+① 的 97% 效果——"单独加模块①"是性价比最高的部署。
4. **工程创新④（步跳）免检通过**：skip=2 耗时降 40%（3.92→2.38s），所有信任指标不降反微升
   ——速度与可信度评估双赢。
5. **融合权重稳健**：w₁∈[0.3, 0.6] 区间内指标变化 <0.01 AUROC，方法对超参不敏感；
   细扫最优在 w₁=0.3 附近（可作为默认值微调依据）。
