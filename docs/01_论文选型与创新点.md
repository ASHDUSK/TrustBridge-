## 一、方法基座：SelfRDB（Self-Consistent Recursive Diffusion Bridge）

- **题目**：Self-Consistent Recursive Diffusion Bridge for Medical Image Translation（Medical Image Analysis，arXiv:2405.06789）
- **任务设定**：**配对（paired）**医学图像翻译：多对比度 MRI（T1/T2/PD/FLAIR）与 MRI→CT。
- **方法要点**：
  1. **软先验扩散桥**：前向过程起点为目标图像 x0、终点为加噪源图像 y_ε；噪声方差 σ²ₜ = γ·sₜ²/(s̄ₜ²+sₜ²) **单调递增至终点**（常规扩散桥在中点达峰、两端为 0），把"硬先验"（Dirac-δ 约束在训练集源图像上）松弛为"软先验"，提升泛化与信息传递；
  2. **自洽递归采样**：反向每一步内，生成器 Gθ(xₜ, t, y, x̃₀ʳ) 递归精化目标图像估计 x̃₀，直到相对变化 <1% 收敛，再用后验采样 q(xₜ₋₁|xₜ, y, x̃₀*)，显著提升采样精度；
  3. 轻量对抗训练（L1 + 判别器）稳定输出。
- **性能**：IXI/BRATS/盆腔 CT 上超过 SynDiff、DDPM、I2SB、pix2pix 等基线（如 IXI T2→T1：PSNR 31.56 dB / SSIM 95.65%）。
- **作者自述未来工作（关键！）**：*"future research is warranted to evaluate the **uncertainty** of diffusion bridges in medical image translation"*——论文明确把"翻译结果的可信度/不确定性评估"留作未解决问题。

**研究定位**：以 SelfRDB 为方法基座，在其"自洽递归采样"机制之上做创新——把递归过程中**被论文丢弃的中间信号**变成面向临床的**可信度量化与质控系统**，并包装成类应用产品。

## 二、创新点设计（在 SelfRDB 基础上）

### 总命题：从"生成一张像"到"生成一张像 + 告诉你哪里可信"
医学图像翻译走向临床的最大障碍不是画质，而是**信任**：合成图像里的幻觉伪影可能误导诊断与放疗剂量计算。SelfRDB 的递归采样天然产生两类被丢弃的信号，我们将其系统化为可信度证据。

### 创新点 1：递归收敛残差场（Recursive Convergence Residual Field, RCRF）——零成本的"幻觉定位图"
- **观察**：论文在每个反向步内做递归估计 x̃₀ʳ → x̃₀ʳ⁺¹，但只用一个**全局标量**（|x̃₀ʳ⁺¹−x̃₀ʳ| 的 mean→max）判断停机；逐像素的残差信息被完全丢弃。
- **创新**：在反向最后若干步收集逐像素递归残差序列 R(p) = meanₜ,r |x̃₀ʳ⁺¹(p) − x̃₀ʳ(p)|，形成空间残差场。
- **含义**：网络在某像素附近反复修改仍不能自洽 → 该处结构先验弱、最可能是"编造"区域。**不需要任何额外模型或标注**，推理时顺带产出。

### 创新点 2：随机桥集成不确定性（Stochastic Bridge Ensemble Uncertainty）
- **观察**：桥的终点是加噪源图像 y_ε、后验采样带随机性——同一源图像多次采样会得到略有差异的目标图像（论文只一句带过"nominal variability"）。
- **创新**：N 次独立采样（不同噪声种子）→ 逐像素标准差图 U(p)；与 RCRF 融合为**信任图** Trust(p) = 1 − w₁·R̂(p) − w₂·Û(p)（归一化后加权融合，权重可配）。
- **含义**：等价于深度集成的近似，但每个成员来自同一桥模型的不同随机路径，成本 = N×10 步×递归（官方 10 步配置下可负担）。

### 创新点 3：图像级可信度评分与自动质控（Trust Score & QC Gate）
- 融合信任图的分位数统计 + 递归收敛曲线（每步残差衰减轨迹）→ 0-100 的 **Trust Score**；
- 设定质控阈值自动给出 PASS / REVIEW / REJECT 三级门控建议；
- 可选**往返一致性**（T1→T2→T1）作为第二证据链，多任务时交叉验证。

### 创新点 4：自适应递归加速（工程创新）
- 论文用固定 max R + 全局阈值；我们实现**逐图自适应停机 + 残差曲线记录**，在"快/平衡/精细"三档预设下平衡质量与耗时，使交互式应用成为可能。

### 创新点有效性验证方案（大创赛答辩关键证据）
在 IXI 测试集（有真值 GT）上：
1. **像素级校准**：Trust(p) 与真实误差 |x̂(p)−GT(p)| 的 Pearson/Spearman 相关；
2. **判别力**：以 Trust 低分像素预测"高误差像素（误差 > 90 分位）"的 AUROC / AUPRC；
3. **稀疏化曲线**：按 Trust 图剔除最不可信的 k% 像素后，剩余区域的 PSNR 提升幅度；
4. **图像级 QC**：Trust Score 与图像级 PSNR 的秩相关，展示 QC 门控的可行性。

## 三、应用形态（实用性设计）

**MedBridge Studio · 医学影像可信翻译工作台**（Gradio Web 应用，本地部署，数据不出院）

### 场景锚定（回答"有什么用"）
1. **MRI-only 放疗计划（sCT 合成）**：盆腔放疗定位若只有 MRI，可用 T1→CT 合成 CT 用于可视化参考/剂量估算——减少一次 CT 扫描与辐射、剂量负担（官方提供 ct_t1_ct / ct_t2_ct 权重）；
2. **缺失序列补全**：T2/PD 序列因扫描时间、运动伪影、造影剂禁忌缺失时由 T1 补全，保证回顾性研究多序列齐套；
3. **AI 输出质控**：每次合成都输出信任热图 + Trust Score + 质控报告（PNG/JSON），可归档、可审计——对齐医学 AI "可信、可解释、可追溯"的监管方向。

### 功能清单
- 输入：PNG/JPG（单切片）、NIfTI（整卷批量翻译→输出 NIfTI）、DICOM；
- 任务：T1↔T2、T1↔PD、PD↔T1（脑 MRI）；T1→CT、T2→CT（盆腔，扩展）；
- 输出：翻译结果、信任热图、叠加标注图、前后对比、（有 GT 时）PSNR/SSIM、质控报告下载；
- 三档质量预设（快/平衡/精细）+ 集成采样数可调；
- 全中文界面，GPU 加速（RTX 4060 8GB 实测目标：单图秒级~十秒级）。

## 四、技术路线

```
third_party/SelfRDB        官方代码与预训练权重（MIT License，规范引用）
trustbridge/               本项目创新层
  ├─ engine.py             ckpt 加载（剥离 Lightning 依赖，直取 Gθ + 扩散调度）
  ├─ sampler.py            TrustSampler：递归残差场捕获 / 集成采样 / 自适应停机
  ├─ trustmap.py           RCRF + 不确定性融合 + Trust Score 计算
  ├─ metrics.py            PSNR/SSIM（对齐官方 utils 实现）
  ├─ report.py             质控报告（PNG 合成图 + JSON）
  └─ io_utils.py           PNG/NIfTI/DICOM 读写、切片填充与归一化
app/app.py                 Gradio 应用（中文 UI）
scripts/prepare_ixi_demo.py 下载 IXI 测试受试者、准备示例切片
scripts/validate_trust.py  创新点有效性验证（相关性/AUROC/稀疏化曲线）
docs/                      项目说明书（大创赛材料）
outputs/                   演示输出与报告
```

### 风险与对策

- 4060 显存 8GB：官方配置 10 步 + 图像 256² + fp16 推理，集成数 N 默认 4~8，实测后调；
