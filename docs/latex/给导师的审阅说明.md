## 一、三个核心结论（我们认为已由证据支撑）

1. **CReF 的价值**：在合适的（模型, 方向）组合上，以零额外生成器前传提供有价值的空间误差排序证据——自训模型上单链 AUROC 0.787/0.705，完整融合 0.823/0.757（患者级配对 Bootstrap 显著，CI [0.003,0.021]/[0.003,0.029]）。
2. **方法的边界**：信号是否有信息是（模型, 方向, 解剖）三元组的属性——官方权重的一个方向上本文信号近随机（0.567）而 TTA 基线弱存活（0.630）；盆腔 CT 上 K₀ 与融合权重的作用均发生改变（权重排序反转 0.698 vs 0.575）。
3. **最重要的警示**：自洽性不等于正确性——崩塌模型（NCC 0.41 结构错误）体区信任 62.4 vs 健康 82.4，只能 REVIEW 不能 REJECT；肿瘤区域信任反而更高（0.792 vs 0.728）而定位能力为随机水平（0.47）。

## 二、主要局限（我们自己的判断）

1. 训练/验证规模小（6–8 名被试），可学习聚合路线因此被关闭；
2. SynthRAD 仅 3 名患者——跨解剖结论是探索性的，无患者级方差；
3. 错位（misalignment）输入无任何内建检测；
4. 偏差型幻觉（自信地错）原理性超出方差型信号——需要外部病理审计闭环；
5. 图像级标量分不可作 QC 门（仅可作分诊启发式）。
