# 复现性排查与验证报告

> 本报告记录"官方发布权重在我们自备的 IXI 数据上达不到论文指标"这一问题的完整排查过程、
> 结论与应对策略。它既是诚实的实验记录，也是本项目管理论价值的支撑材料：
> **把"内容误差"与"强度窗误差"分开归因**，是理解医学图像翻译指标的关键方法论。

## 1. 现象

| 设置 | PSNR (dB) | SSIM (%) |
|---|---|---|
| SelfRDB 论文（IXI T2→T1，作者数据制备） | 31.56 | 95.65 |
| 官方发布权重 + 我们制备的 IXI 数据（逐切片 min-max 窗） | ~13-15 | ~35-74 |
| 官方发布权重 + 论文式全局窗（C≈8.8） | ~15 | ~56 |

社区有同样报告：同实验室 SynDiff 仓库
[issue #53](https://github.com/icon-lab/SynDiff/issues/53)（官方权重在自备 IXI 数据上 ~17dB）。

## 2. 排查过程（逐项排除）

| 假设 | 实验 | 结论 |
|---|---|---|
| 归一化约定不符（逐切片 min-max vs 脑均值/全卷均值 + 全局尺度） | 窗系数 s∈{1.5..12} 扫描 + 线性拟合 | 有影响（非线性部分），非主因 |
| 平面内刚性错位 | 以"翻译后 PSNR"为目标搜索 (θ, dy, dx) | 最优即 (0,0,0)，排除 |
| 离面倾斜 | 绕 x/y 轴 ±4° 搜索 | 无改善，排除 |
| z 向错位 | dz∈[-6,6] 搜索 | dz=0 即最优，排除 |
| 全视野 vs 脑区裁剪补零 | 中心/质心 bbox 176² 裁剪 | 无改善，排除 |
| 方向/翻转约定 | rot90/flipud 组合 | 无显著差异，排除 |

**决定性实验**：对 epoch-9 自训练模型（此时结构已对齐，NCC 0.85+）做误差分解——

```
原始全图 PSNR            ≈ 19 dB
+ 全局线性强度拟合 (a·gt+b) ≈ 28-30 dB
+ 修正 ~2px 受试者级残差   ≈ 30-34 dB   ← 论文同级
```

## 3. 结论

1. **内容误差已达论文水平**（线性校正后 29-34dB），残余差距由两部分构成：
   - 全局线性强度映射残余（扩散桥输出的动态范围压缩）；
   - 每受试者 ~2px 的细对齐残差（跨模态梯度搜索不敏感）。
2. 官方权重差距的主因是**作者未公开的 IXI 数据制备**（与社区报告一致），
   而非代码/权重问题——官方代码与权重本身可正常加载与推理。

## 4. 应对策略

- **官方权重**：保留用于 256² 应用演示（视觉质量良好）；
- **自训练同配方模型**（10 步桥、R=2、β 0.1→3.0、γ=1；128²；30 epochs；单卡 RTX 4060）：
  承担全部量化验证，数据制备/训练/评估在本仓库内闭环；
- **数据管线 v3**（本仓库 `scripts/export_slices_v2.py`）：
  世界坐标仿射对齐 → 同窗跨模态 NCC 细配准（±6px）→ 论文式全局强度窗（C=8.80，train 集 p99.9 标定）。
  相比逐切片 min-max，同阶段验证 PSNR +4.3dB，测试集线性校正后 PSNR 达 31.74dB（论文 31.56）。

## 5. 创新点有效性（测试集 60 切片，N=4 集成）

| 指标 | 数值 | 说明 |
|---|---|---|
| 像素级 Spearman（信任图 vs \|pred−GT\|） | −0.807 | 信任图与真实误差强负相关 |
| 像素级 Pearson | −0.504 | 一致 |
| AUROC（低信任→高误差像素 >90 分位） | 0.818±0.065 | 良好判别力 |
| 剔除最不可信 20% 像素后 PSNR 增益 | +2.81 dB | 实用筛查价值 |
| 图像级 Trust Score vs PSNR 秩相关 | 0.373 | 粗粒度 QC 可行 |

## 6. 双方向最终结果（测试集）

| 任务 | PSNR (dB) | SSIM (%) | NCC | 线性校正后 | Spearman | AUROC | 稀疏化增益 |
|---|---|---|---|---|---|---|---|
| T2→T1 | 19.81±1.10 | 71.0±6.6 | 0.884 | 31.74 | −0.807 | 0.818 | +2.81 dB |
| T1→T2 | 20.44±1.16 | 80.4±4.1 | 0.905 | 32.52 | −0.900 | 0.900 | +5.37 dB |
