# 公开文件审核清单（PUBLISH_CHECKLIST）

> 任何新增/修改文件进入公开分支前，项目负责人逐条核对。
> 命中"迁出"项的材料一律移入仓库外本地归档，不删除原始内容。

## 提交前八查

1. **身份与内部语境**：是否含人名、导师、单位、申报（大创赛）语境？→ 迁出归档
2. **本机信息**：是否含 `D:\` 等本地绝对路径、.bat 启动器、代理配置、机器名？→ 清除或通用化
3. **Agent 协作痕迹**：是否含 Agent 规范、任务指令、交接材料、修改前后对照记录？→ 迁出归档
4. **学习材料**：论文精读教程、个人笔记、写作风格分析、问题清单？→ 迁出归档
5. **数据授权**：是否新增影像数据/切片图/权重/系数？→ 对照 [DATA.md](DATA.md) 许可表，未登记许可不得入库
6. **临时脚本**：`_patch*` / `_tmp*` / 一次性重算脚本？→ 不入库（本地归档）
7. **两仓库边界**：论文源 / 论文实验结果 / 审计文档 → 只进 TrustBridge-Paper；
   UI / 部署 / 用户文档 / 软件评估 → 只进本仓库。同一份正式材料不得双仓库长期并存
8. **文档引用**：新增代码注释与 README 是否引用了真实存在的路径（禁止引用已归档的编号文档）
